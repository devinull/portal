# Portal v0.0.1

Portal begins as a fast, keyboard-driven terminal command center for the
machines already connected to your private network. It discovers Tailscale
desktop peers, checks their actual reachability, and launches RustDesk desktop
or file-transfer sessions without routing commands through a shell.

## Highlights

- Interactive terminal interface with live Tailscale peer discovery, sequential
  TSMP availability checks, latency display, keyboard navigation, and
  deterministic sorting.
- Connect and file-transfer actions for RustDesk, plus preview-first Windows
  RustDesk receiving configuration.
- Local address-book metadata: give machines nicknames, tags, favorites, and
  notes directly in the TUI with `e`; Portal writes those changes to its TOML
  configuration and shows them in the details panel.
- Theme picker with Portal, Hacker, Terminator, Cyber Cyan, and configurable
  custom palettes. The selected theme is saved as the default.
- `portal setup` checks Tailscale and RustDesk availability and, when possible,
  offers a platform-native package manager, the official download page, or a
  skip option. It never downloads or runs a shell bootstrap script.
- Windows installer with dark native-style presentation, current-user or
  all-users installation, install-location selection, optional PATH updates,
  uninstaller support, and a portable ZIP alternative.

## Downloads

Choose the asset that matches your operating system and processor:

- **Windows x86_64:** `PortalSetup-0.0.1-x86_64.exe` is the installer;
  `portal-0.0.1-x86_64-pc-windows-msvc.zip` is the portable archive.
- **macOS:** install `Portal-0.0.1-aarch64.pkg` for Apple Silicon or
  `Portal-0.0.1-x86_64.pkg` for Intel. Portable `.tar.gz` archives are also
  provided for both architectures.
- **Linux:** select the matching x86_64 or ARM64 DEB, RPM, or portable
  `.tar.gz` archive.

Every draft release includes `SHA256SUMS` for integrity verification and GitHub
artifact attestations for the built assets.

## Before you start

Portal requires Tailscale and RustDesk on the controller and remote devices.
Authenticate Tailscale, enable RustDesk direct-IP access on the targets, then
run `portal`. Portal does not collect or store Tailscale credentials, RustDesk
passwords, raw network status, probe output, or private tailnet names.

## Platform notes

Windows has received runtime and installer validation. macOS and Linux assets
are built and packaged by CI, but their first-release runtime validation still
needs confirmation on clean physical machines. Unsigned or unnotarized assets
may prompt operating-system security warnings until the relevant signing secrets
are configured for the repository.

## What is next

The roadmap includes additional private-network providers beginning with
ZeroTier, plus modern SSH and agent-ready remote terminals with explicit,
safe execution boundaries. See [the roadmap](https://github.com/devinull/portal/blob/v0.0.1/docs/roadmap.md).
