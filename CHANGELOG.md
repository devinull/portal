# Changelog

All notable Portal changes are documented here. Portal uses semantic versioning
for tagged releases.

## [0.0.1] - 2026-08-13

### Added

- Cross-platform CLI and responsive terminal interface.
- Tailscale desktop-peer discovery with stable node identities.
- Sequential active TSMP availability checks and operational latency display.
- RustDesk desktop and file-transfer launch actions.
- Optional nicknames, tags, favorites, notes, themes, and last-used state.
- Preview-first Windows RustDesk receiving configuration.
- Dark Windows installer, portable archives, native packages, and automated
  draft GitHub Releases.
